================================================================================
Tina Android IDE Client (Qt Quick + C++23 + Rust/C++ FFI) 分阶段开发计划
================================================================================

本项目 (`android_app/`) 是 Tina Fedora 远程开发工作台（Server）的客户端 IDE，
基于 Qt 6 (Qt Quick / QML) + C++23 构建，支持 16:10 横屏平板/桌面毛玻璃交互体验，
并通过 FFI / C++ Bridge 与后端 RPC 通信层对接。

--------------------------------------------------------------------------------
阶段一（Phase 1）：前端 UI 外壳与交互原型搭建（当前阶段）
--------------------------------------------------------------------------------
目标：搭建完整的 16:10 暗色毛玻璃（Glassmorphism）风格 IDE 外壳，跑通纯前端视觉与交互逻辑。
任务清单：
1. 初始化 `android_app` 下的 CMake + Qt6 Quick + C++23 工程结构（兼容桌面预览与 Android 构建）。
2. 全局视觉规范：16:10 横屏布局、背景壁纸渲染、统一的高斯模糊（MultiEffect）+ 半透明暗色圆角玻璃组件（GlassPanel）。
3. 顶部/中部的全屏代码编辑区（位于左右红色虚线分割线以内，高度占满整个屏幕上下边界）。
4. 左侧单文件标签页栏（贴近屏幕左侧，纵向间隔罗列，毛玻璃半透明胶囊/圆角卡片，选中态高亮，底部对齐输入框）。
5. 底部命令行/交互输入栏：
   - 整体毛玻璃圆角条，默认作为命令行（Terminal/Command）输入，除非首字符为 `@`。
   - 左侧 Folder 按钮（①）：点击后对齐输入框上方弹出透明模糊窗口（当前留空占位）。
   - `@` 触发弹窗：当输入框第一个字母输入 `@` 时，对齐输入框弹出 GIT / FILE / TERMINAL 三行菜单。
   - 右侧向上箭头按钮（②）：点击或回车触发提交。

--------------------------------------------------------------------------------
阶段二（Phase 2）：FFI 桥接层与客户端 RPC 通信接入
--------------------------------------------------------------------------------
目标：打通 Qt C++23 前端与底层 RPC Client（C++ `rpc::RpcClient` / Rust FFI Client）的双向异步调用与事件推送。
任务清单：
1. 设计 C ABI / C++ FFI 接口层（`tina_client_ffi.h` / Bridge 模块），封装连接管理、请求发送（`async_call`）与服务端 Event 回调。
2. 实现 Qt `QObject` / `QML_ELEMENT` 控制器（如 `TinaBridge`、`SessionController`），将后台 I/O 线程的响应通过 `QMetaObject::invokeMethod` 安全投递回 Qt 主线程。
3. 接入 `system.ping`、连接状态监控、断线检测与自动重连。

--------------------------------------------------------------------------------
阶段三（Phase 3）：Workspace 文件树、多标签代码编辑与命令执行
--------------------------------------------------------------------------------
目标：将左侧 Folder 弹窗、文件标签页、主代码区与底部命令行接入真实的 Fedora Server 服务。
任务清单：
1. 完善左下角 Folder 弹出窗口：接入 `workspace.list` / `file.tree`，展示远程项目目录树。
2. 联动左侧文件标签页与中间代码编辑区：点击文件打开对应 Tab，读取远程 UTF-8 文件内容、支持语法高亮、编辑修改与保存写回。
3. 联动底部命令行输入框：非 `@` 开头的内容直接作为 Shell 命令发送至远程 PTY / Terminal 服务并回显结果。

--------------------------------------------------------------------------------
阶段四（Phase 4）：@ 上下文菜单与 Android 打包调优
--------------------------------------------------------------------------------
目标：完善文件、Git 和终端的 `@` 弹窗交互，以及 Android 平板真机体验。
任务清单：
1. 完善 `@` 弹出模糊窗口：提供 `@file`、`@git`、`@terminal` 上下文候选列表。
2. 折叠文件树分支时调用 `workspace_close_dir`，取消该分支各已加载目录的监听；重新展开时获取最新列表。
3. 针对 Android 平板（16:10 横屏、虚拟键盘顶起布局、触控手势、60/120fps 高斯模糊渲染性能）进行真机打包（APK/AAB）与调优。
